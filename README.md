# TOP.FATMEYN — Professional GitHub Pages Website

A responsive, futuristic personal brand/learning website inspired by the supplied visual reference.

## Included
- Responsive desktop/tablet/mobile design
- Neon green + gold futuristic UI
- Animated hero section and counters
- Skills roadmap cards
- Interactive Quick Lab
  - Color Lab
  - Typing Sprint
  - Idea Generator
  - Focus Timer
- Local Notes tool using browser localStorage
- Learning progress slider
- Contact form UI
- Mobile navigation
- Dark futuristic theme
- GitHub Pages GitHub Actions deployment workflow

## Run locally
Open `index.html` in a browser.

## Deploy on GitHub Pages
1. Create a GitHub repository.
2. Upload all files in this ZIP to the repository root.
3. Use the `main` branch.
4. Go to **Settings → Pages → Build and deployment → Source** and select **GitHub Actions**.
5. Push/commit the files. The included workflow deploys the site automatically.

Your GitHub Pages address will normally look like:
`https://YOUR-USERNAME.github.io/REPOSITORY-NAME/`

## Customize
Edit the text in `index.html` and colors/visuals in `style.css`.
For real WhatsApp/social links, replace the relevant links with your own URLs.
